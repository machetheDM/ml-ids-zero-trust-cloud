## 🎯 Research Objective

Benchmark ML models for cloud intrusion detection within a Zero Trust Architecture (NIST SP 800-207) framework — determining which model best suits each ZTA pillar.

---

## 📊 Results

| Model | Accuracy | FPR | Best ZTA Pillar |
|-------|----------|-----|----------------|
| LSTM | **98.1%** | **1.8%** | Network monitoring |
| Random Forest | 96.3% | 2.4% | Identity verification |
| XGBoost | 95.8% | 2.9% | Data access control |
| SVM | 94.1% | 3.7% | Application security |
| Autoencoder | 91.2% | 5.1% | Anomaly detection |

Dataset: NSL-KDD (148,000 records)

---

## 🏗️ Zero Trust Architecture Framework

Each model mapped to NIST SP 800-207 ZTA pillars across a 6-phase cloud security implementation roadmap:

1. Identity verification
2. Device compliance
3. Network segmentation
4. Application security
5. Data access control
6. Monitoring and analytics
